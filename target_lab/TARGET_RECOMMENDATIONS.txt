Purpose
-------
This file lists candidate protein targets for agent-driven single-target
optimization. These targets are for target_lab experiments only. A strategy
found here must not be promoted to the ranked casp16_protein_v1 leaderboard
until it is converted into a target-agnostic protocol and rerun over the full
eligible benchmark set.

1. H1258 - primary target-lab recommendation

   Track: protein_oligo
   System: LRRK2/14-3-3 complex, reference 9ci3
   Size: 3092 aa, 3 chains, stoichiometry A1B2
   Current local DockQ: 0.296
   CASP16 per-target best reference point: DockQ_Avg about 0.751 for H1258TS052_2

   Why pick it:
   - It already runs to completion, unlike the largest OOM cases.
   - The current score is low enough to leave real headroom.
   - It is large and biologically realistic, so improvements are likely to
     exercise MSA, template, stoichiometry, chain expansion, and interface
     modeling.
   - CASP16 top groups did much better on this target, so it is a meaningful
     stress test rather than a solved easy target.

   Good first experiments:
   - Verify H1258-only input generation and H1258-only output scoring.
   - Recover official A1B2 stoichiometry before interpreting any complex score;
     older server-benchmark inputs collapsed this target to A1B1 when
     `Oligo.State` was `UNK`.
   - Test a target_lab LRRK2 interaction-domain window before trying to force
     the full A1B2 assembly through Protenix. CASP16 complex assessment notes
     that top Yang models used the interacting LRRK2 region rather than the
     full-length chain.
     Artifact: `target_lab/h1258_interaction_window_v1/`.
   - Compare full A1B2 prediction against smaller subcomplex jobs such as A1B1
     or B2, but keep these as target_lab diagnostics.
   - Try stricter MSA/template cache reuse and record exact MSA parameters.
   - Add chain/stoichiometry sanity checks before running expensive inference.

   Success bar:
   - Short-term: DockQ > 0.40.
   - Strong result: DockQ > 0.55.
   - CASP-top-like target: DockQ around 0.70+.

   Source note:
   - CASP16 protein-complex assessment preprint discusses the H1258 LRRK2
     interaction-domain modeling clue. Keep this as target_lab evidence, not a
     ranked per-target oracle.

Recommended code changes before running agent loops
---------------------------------------------------

1. Add target-scoped run specs.
   Run specs should include:

     target_ids: ["H1258"]
     optimization_scope: "target_lab"
     rank_eligible: false

2. Add strict prediction manifests.
   Scoring should read an explicit mapping:

     target_id -> prediction_path

   Do not score H0258 with an H1258 prediction just because they share a
   reference or description.

3. Add score-target.
   A target_lab scorer should write to:

     target_lab/<target_id>/scores.csv

   It should not rewrite the ranked leaderboard artifacts.

4. Add promotion rules.
   A target-specific trick can be promoted only after it becomes a target-
   agnostic strategy and is rerun over the full eligible benchmark set.
